# IBM Applied Data Science Capstone Project

## SpaceX Falcon 9 First Stage Landing Prediction

### Project Overview
This project aims to predict whether the first stage of a SpaceX Falcon 9 rocket will successfully land after launch. Predicting landing success can help estimate launch costs and support data-driven decision-making.

### Objectives
- Collect launch data using the SpaceX API.
- Gather additional launch information through web scraping.
- Clean and prepare the dataset.
- Perform exploratory data analysis using Python and SQL.
- Create data visualizations and interactive dashboards.
- Build and evaluate machine learning classification models.
- Identify factors that influence first-stage landing success.

### Tools and Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL and SQLite
- Folium
- Plotly and Dash
- Scikit-learn
